# BlueShield 🛡️

**צנזור וידאו אוטומטי ומקומי.** BlueShield מנתח סרטון פריים אחר פריים, מזהה עור חשוף ואזורי גוף רגישים, ומכסה אותם בשכבה כחולה (אחידה או מונפשת בעדינות) שעוקבת אחרי צורת הגוף ואחרי התנועה. שאר הסרטון נשאר ללא שינוי.

> 🔒 **הסרטונים שלך מעובדים מקומית ואינם מועלים.** השרת מאזין רק ל-`127.0.0.1`, וממשק המשתמש לא טוען שום משאב חיצוני.

הכלי מיועד לצנזור בלבד: הוא מזהה ומסתיר אזורים, ולעולם לא יוצר, משפר או משחזר תוכן.

## הפעלה מהירה

### דרישות
| רכיב | גרסה |
|---|---|
| Python | 3.10 – 3.12 |
| Node.js | 18 ומעלה (רק לבניית הממשק) |
| FFmpeg + FFprobe | כל גרסה עדכנית, זמינים ב-PATH |

התקנת FFmpeg: ‏macOS ‏`brew install ffmpeg` · ‏Ubuntu/Debian ‏`sudo apt install ffmpeg` · ‏Windows ‏`winget install Gyan.FFmpeg`

### macOS / Linux
```bash
./start.sh
```

### Windows
```bat
start.bat
```

הסקריפט יוצר סביבה וירטואלית (`.venv`), מתקין את התלויות, בונה את הממשק, מוריד את המודלים ופותח את
**http://127.0.0.1:8765** בדפדפן. בהפעלות הבאות הוא מדלג על מה שכבר הותקן.

### הפעלה ידנית
```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r backend/requirements.txt
(cd frontend && npm install && npm run build)
python scripts/download_models.py        # אופציונלי, קורה גם אוטומטית בהפעלה
cd backend && python run.py --open        # --port 9000  --host 127.0.0.1
```

### מצב פיתוח (Hot reload לממשק)
```bash
cd backend && python run.py               # מנוע על פורט 8765
cd frontend && npm run dev                # ממשק על http://127.0.0.1:5173 (מעביר את /api למנוע)
```

## המודלים: מקור והתקנה

שני המודלים בקוד פתוח, ורצים מקומית לגמרי. הם מותקנים לתיקייה `backend/models/` בהפעלה הראשונה (או ידנית עם `python scripts/download_models.py`):

| מודל | תפקיד | מקור | רישיון |
|---|---|---|---|
| **MediaPipe Selfie Multiclass 256** (‏Google) | סגמנטציה ברמת הפיקסל: רקע / שיער / **עור גוף** / עור פנים / בגדים / אחר. זה מה שנותן למסכה את הצורה המדויקת של הגוף | יורד מ-`storage.googleapis.com/mediapipe-models/…/selfie_multiclass_256x256.tflite` (כ-16MB) | Apache-2.0 |
| **NudeNet v3 ‏(320n)** | גלאי YOLOv8 (ONNX) לאזורים רגישים חשופים: חזה, ישבן, איברי מין | נכלל בחבילת ה-pip ‏`nudenet` (מותקנת מ-requirements) ומועתק לתיקיית המודלים. גיבוי: GitHub Releases של notAI-tech/NudeNet | MIT |

אחרי ההורדה הראשונה אין צורך באינטרנט.

## איך זה עובד

```
            ┌──────────────────── מעבר 1: ניתוח וזיהוי (רזולוציה ≤640px) ────────────────────┐
 FFmpeg ──► │ זיהוי חיתוכי סצנה ► Optical Flow ► סגמנטציית עור בפריימי מפתח                 │
 (pipe)     │   ► NudeNet בבאצ'ים ► מעקב תיבות (IoU + חיזוי תנועה) ► מיזוג זמני נגד הבהוב    │ ──► מאגר מסכות דחוס בדיסק
            └──────────────────────────────────────────────────────────────────────────────┘
            ┌──────────────────── מעבר 2: החלה וקידוד (רזולוציה מקורית) ─────────────────────┐
 FFmpeg ──► │ קריאת מסכה (+look-ahead) ► הגדלה ב-ROI בלבד ► הרחבה + ריכוך שוליים ► מילוי כחול │ ──► FFmpeg ‏H.264 + אודיו מקורי ► MP4
 (pipe)     └──────────────────────────────────────────────────────────────────────────────┘
```

* **סגמנטציה ולא מלבנים:** המסכה נבנית מהסתברות "עור גוף" לכל פיקסל, כך שהכחול עוקב אחרי קווי המתאר של הידיים, הרגליים, הגו וכו'. אזורים רגישים שמזוהים ע"י NudeNet מכוסים באליפסות רכות שעוקבות אחריהם.
* **מעקב זמני:**
  * **Optical flow** (‏Farneback) מעביר את המסכה בין פריימי מפתח, כך שאין צורך להריץ את המודל על כל פריים, והמסכה "נדבקת" לאדם שזז.
  * **Attack מהיר / Release איטי:** זיהוי חדש מופיע מיד, וזיהוי שנעלם לרגע דועך לאורך כמה פריימים במקום להבהב.
  * **Hysteresis:** סף גבוה להדלקת פיקסל וסף נמוך להשארתו דולק, כדי למנוע ריצוד בשוליים.
  * **מעקב תיבות** שמחזיק אזור רגיש גם כמה סבבי זיהוי בלי התאמה (טשטוש תנועה, הסתרה, יציאה חלקית מהפריים).
  * **זיהוי חיתוך סצנה** מאפס את המצב, ופריימי מפתח נוספים נכפים בתנועה מהירה. כשאדם נכנס מחדש לפריים, הוא מזוהה בפריים המפתח הבא, ו-look-ahead קצר במעבר 2 מכסה גם את הפריימים שלפניו.
* **ביצועים:** ‏FFmpeg מפענח ומקודד בתהליכים מקבילים דרך pipes (הסרטון לעולם לא נטען כולו ל-RAM). המסכות נשמרות דחוסות בדיסק בין המעברים. ‏NudeNet רץ בבאצ'ים. העיבוד מתבצע רק בתוך התיבה התוחמת של האזור המצונזר, ופריימים בלי זיהוי עוברים כמעט בלי עלות. ‏LiteRT (‏XNNPACK) מריץ את הסגמנטציה על כל ליבות ה-CPU.

### האצת GPU
* **זיהוי:** אם מותקנת חבילת `onnxruntime-gpu` (‏CUDA) או `onnxruntime-directml` (‏Windows), המנוע בוחר את ה-provider המתאים אוטומטית:
  `pip uninstall onnxruntime && pip install onnxruntime-gpu`
* **קידוד:** ‏`h264_nvenc` / `h264_videotoolbox` / `h264_qsv` מזוהים ונבדקים אוטומטית. אם אף אחד מהם לא זמין, המנוע חוזר ל-`libx264`.
* סטטוס ההאצה מוצג בכותרת הממשק ("GPU accelerated" / "CPU mode").

## הממשק

* העלאה בגרירה, עם תמיכה ב-MP4, ‏MOV, ‏WebM, ‏MKV, ‏AVI, ‏WMV, ‏FLV, ‏MPEG, ‏3GP, ‏TS ועוד. פורמטים שהדפדפן לא מנגן מקבלים אוטומטית proxy לתצוגה מקדימה.
* פרטי קובץ: שם, משך, רזולוציה, FPS, גודל, אודיו.
* הגדרות: צבע (פלטה + בורר חופשי), אנימציית shimmer, רגישות זיהוי, רכות מסכה, **מצב צנזור אגרסיבי**, כיסוי פנים, מהירות/איכות, ואיכות ייצוא.
* מסך עיבוד מונפש עם השלבים *Analyzing video… → Detecting sensitive regions… → Applying censorship… → Encoding final video…*, אחוז התקדמות, פריים נוכחי מתוך סה"כ, זמן משוער שנותר, מהירות, **תצוגה חיה** של הזיהוי, וכפתורי השהיה, המשך וביטול.
* בסיום (**Censorship complete.**): השוואה **צד-לצד** מסונכרנת (מקור משמאל, מצונזר מימין), **סליידר השוואה נגרר**, או מצונזר בלבד. מתחת לסרגל הזמן מוצגת מפת חום של הצנזור, ויש מעבר פריים-פריים (←/→) ומקש רווח להפעלה ועצירה.
* כפתור **Export MP4** בולט: ‏H.264, רזולוציה ו-FPS מקוריים, אודיו מקורי (AAC).

## מגבלות ידועות
* מודל הסגמנטציה עובד על תמונה של ‎256×256‎, ולכן הוא מדויק יותר כשהאנשים בפריים בגודל בינוני או גדול. בצילומים רחבים עם אנשים קטנים כדאי להפעיל **Aggressive**, שמוסיף סריקה באריחים (tiles) וגלאי צבע עור כגיבוי.
* "עור גוף" כולל גם צוואר, ולכן המסכה עשויה לגעת בקצה הסנטר. לכיסוי מלא של הפנים הפעילו את **Also cover faces**.
* זיהוי אוטומטי אינו מושלם. לפני הפצה, מומלץ לעבור על התוצאה בתצוגת ההשוואה.
* על Linux, הגיבוי ל-MediaPipe (בשימוש רק אם LiteRT לא זמין) דורש `libegl1`.
